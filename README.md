# groominggang-com

One-page public landing website for **The Grooming Gang Coverup** with:

- a single prominent button linking to Amazon: https://www.amazon.co.uk/dp/0995584982/
- a simple frame ready for the book cover image upload
- a two-colour palette: `#124B44` and white

## Files

- `index.html`
- `styles.css`

## Adding the book cover image

Replace the `.book-frame` placeholder in `index.html` with an `<img>` tag when the cover image is ready.
